# PulseStorageSetDataCallback delegate

`PulseStorageSetDataCallback`

```csharp
public delegate int PulseStorageSetDataCallback(string key, string value, IntPtr user_context);
```

| parameter | description |
| --- | --- |
| key | A string containing the key the data should be stored under. |
| value | A string containing the data to be stored under the key. If value is NULL, this indicates a deletion. |
| user_context | The user context configured with this callback. |

## Return Value

0 on success and -1 on error. Deletion of a non-existing key should return success.

## Remarks

If an error occurs, it is the responsibility of the callback to ensure that no partial data is persisted.
