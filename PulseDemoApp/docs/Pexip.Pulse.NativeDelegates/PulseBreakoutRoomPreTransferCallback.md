# PulseBreakoutRoomPreTransferCallback delegate

`PulseBreakoutRoomPreTransferCallback`

Callback function to inform about an imminent breakoutroom transfer.

```csharp
public delegate void PulseBreakoutRoomPreTransferCallback(uint room_id, string breakout_room_name, 
    IntPtr user_context);
```

| parameter | description |
| --- | --- |
| room_id | The room id. |
| breakout_room_name | The name of the room the client is about to be transferred to. |
| user_context | The user context configured with this callback. |

## Remarks

The transfer will not be performed until after this callback has returned, so this is a good place to optionally wait a few seconds while displaying information about the transfer to the client.

There is no option to cancel the transfer.

This callback is emitted for both HOST and GUEST participants.
