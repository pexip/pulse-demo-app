# PulseSSOProviderRequestCallback delegate

`PulseSSOProviderRequestCallback`

Callback function to perform the SSO Provider Request call, parse the response, and return the sso-token via the provided PulseSSOProviderSetToken function. Note: The included PulseSSOProviderSetToken function must be called prior to returning from this callback.

```csharp
public delegate bool PulseSSOProviderRequestCallback(PulseSSOProviderRequest request, 
    PulseSSOProviderSetToken setToken, IntPtr user_context);
```

| parameter | description |
| --- | --- |
| request | A PulseSSOProviderRequest structure containing the information needed to perform an SSO authentication. |
| setToken | A PulseSSOProviderSetToken structure containing a function pointer and context, used for storing a new sso-token. |
| user_context | The user context configured with this callback. |

true if the request was successful, flase elsewhere
