# PulseConnect.pulse_connect_with_rest_async method

Pulse with public REST communication handling.

This function handles all parts of the communication setup - provide it with a set of connections parameters, and it takes will setup all you need. In many cases, you want to set one or more pulse_options prior to calling connect, to set specific behavior or registering callbacks for eg SSO.

```csharp
public static PulseErrorType pulse_connect_with_rest_async(IntPtr client, 
    PulseRestConnectionConfig connection_params, 
    PulseAsyncOperationResultCallbackConfig result_callback_config, 
    PulseOperationProgressCallbackConfig progress_callback_config)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| connection_params | PulseRestConnectionConfig struct type, with the necessary information filled in. |
| result_callback_config | Mandatory callback function for receiving the error code from the execution of the async function, once it is done. |
| progress_callback_config | An optional callback function with user_context, for receiving progress updates during disconnect. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available when running the Pulse in public rest handling modes.
