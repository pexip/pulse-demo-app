# PulseConnect.pulse_send_message method

`Send message to one or all participants`

This function sends a message to all participants in the conference.

```csharp
public static PulseErrorType pulse_send_message(IntPtr client, string? target_participant_uuid, 
    PulseMessageRequest request)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| target_participant_uuid | A string containing the uuid of the participant to send message to. If NULL, it will be sent to all participants. In a direct media call, this is not used. |
| request | A pointer to a PulseMessageRequest struct type with all necessary arguments filled in. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.
