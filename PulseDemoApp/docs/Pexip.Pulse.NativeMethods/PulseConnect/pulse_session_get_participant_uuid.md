# PulseConnect.pulse_session_get_participant_uuid method

`Get the client participant uuid for the conference.`

This function returns the clients participant uuid.

```csharp
public static PulseErrorType pulse_session_get_participant_uuid(IntPtr client, uint room_id, 
    out IntPtr uuid)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| room_id | The room id to fetch participant UUID for. |
| uuid | A pointer reference to a chartype. Upon successful return, the reference will be set to point to a newly allocated zero terminated buffer containing the participant UUID. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

Use pulse_session_free_participant_uuid function to free the participant uuid buffer.
