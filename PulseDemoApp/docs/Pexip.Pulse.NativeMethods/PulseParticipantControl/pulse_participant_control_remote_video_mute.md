# PulseParticipantControl.pulse_participant_control_remote_video_mute method

`Video mute a remote participant.`

This functions mutes/unmutes video input from the participant identified by the target_participant_uuid.

```csharp
public static PulseErrorType pulse_participant_control_remote_video_mute(IntPtr client, 
    string target_participant_uuid, bool mute)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| target_participant_uuid | UUID of the target participant. Set to NULL for targeting this client. |
| mute | boolean indicating the new mute state for the targeted participant, true to mute or false to unmute. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

Cannot be used to alter mute state of the local participant. See pulse_mute_video_input().

This function can only be called when the session has role HOST.
