# PulseRegistration.pulse_registrations_get_connected_server method

`Get the resolved address of the connected registration server.`

Get the resolved address of the connected registration server.

```csharp
public static PulseErrorType pulse_registrations_get_connected_server(IntPtr client, 
    out IntPtr connected_server)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| connected_server | Reference to a char variable, that will have point to a character buffer holding the resolved server address, if the call to this function returns successfully. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available when running the Pulse in public rest handling modes

The returned string must be dereferenced by the client, by calling the pulse_registrations_connected_server_free() function.
