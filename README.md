# Pexip Pulse Demo App

<br/>

This is a.NET getting started sample application that demonstrates the use of Pexip PULSE SDK, built using .NET and Infinity Conferencing Platform.

## Technologies

- [.NET 8](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- [WinUI 3](https://learn.microsoft.com/en-us/windows/apps/winui/winui3/)
- [Pexip Pulse SDK](https://www.pexip.com/)
- [MSIX](https://learn.microsoft.com/en-us/windows/msix/overview)
