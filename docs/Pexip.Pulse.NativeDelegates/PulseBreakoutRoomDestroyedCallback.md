# PulseBreakoutRoomDestroyedCallback delegate

`PulseBreakoutRoomDestroyedCallback`

Callback function to inform that a existing breakout room was destroyed.

```csharp
public delegate void PulseBreakoutRoomDestroyedCallback(uint room_id, IntPtr user_context);
```

| parameter | description |
| --- | --- |
| room_id | The UUID of the room the client was transferred to. For the main room, this is NULL. |
