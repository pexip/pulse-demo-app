# PulseBreakoutRoomCreatedCallback delegate

`PulseBreakoutRoomCreatedCallback`

Callback function to inform that a new breakout room was created.

```csharp
public delegate void PulseBreakoutRoomCreatedCallback(uint room_id, IntPtr user_context);
```

| parameter | description |
| --- | --- |
| room_id | The UUID of the room the client was transferred to. For the main room, this is NULL. |
| user_context | The user context configured with this callback. |

## Remarks

This callback is only emitted for HOST participants.

This callback can be called multiple times for the same uuid, if eg. a network change or error occurred. In this case, the state of the room (conference_stataus and participant lists) will be recreated completely.
