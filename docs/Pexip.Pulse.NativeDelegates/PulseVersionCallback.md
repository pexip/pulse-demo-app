# PulseVersionCallback delegate

`PulseVersionCallback`

Callback function to inform that the attempted connection is done to a server of unsupported version.

```csharp
public delegate bool PulseVersionCallback(ulong server_major_version, ulong server_minor_version, 
    IntPtr user_context);
```

| parameter | description |
| --- | --- |
| server_major_version | The major version of the Infinity server we're attempting to connect to. |
| server_minor_version | The minor version of the Infinity server we're attempting to connect to. |
| user_context | The user context configured with this callback. |

## Return Value

This callback should return TRUE(1) if we accept the connection even though its unsupported, or FALSE(1) if we want to stop this connection.
