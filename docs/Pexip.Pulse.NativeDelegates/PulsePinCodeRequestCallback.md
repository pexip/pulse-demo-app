# PulsePinCodeRequestCallback delegate

`PulsePinCodeRequestCallback`

Callback functions for querying a client for a pin code.

```csharp
public delegate bool PulsePinCodeRequestCallback(bool guest_pin_required, 
    PulseSetPinCode pin_set_pin_code, IntPtr user_context);
```

| parameter | description |
| --- | --- |
| guest_pin_required | True if a pin code is required for joining as a guest, False otherwise. |
| pin_set_pin_code | A PulseSetPinCode struct containing a function pointer for setting the pin code. |
| user_context | The user context that was configured for this callback. |

## Return Value

True if the user accepted the Pin Code Request or False otherwise

## Remarks
