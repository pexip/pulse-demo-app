# PulseConnect.pulse_cancel_request method

`Cancel a request.`

This function allows you to cancel a running pulse_connect_with_rest()/pulse_connect_with_rest_async() call. If the process was successfully cancelled, the return code for that call will return PULSE_ERROR_PROCESS_ABORTED.

```csharp
public static PulseErrorType pulse_cancel_request(IntPtr client)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available when running the Pulse in public rest handling modes
