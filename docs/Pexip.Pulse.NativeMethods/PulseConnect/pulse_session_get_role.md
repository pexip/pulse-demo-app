# PulseConnect.pulse_session_get_role method

`Get the client role in the conference.`

This function returns the clients role in the conference, either PULSE_CONFERENCE_ROLE_HOST or PULSE_CONFERENCE_ROLE_GUEST.


| parameter | description |

| client | The Pulse handle |
| role | A pointer to a PulseConferenceRole type. Upon successful return, the result will be written here. |
