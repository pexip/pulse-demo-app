# PulseConferenceControl.pulse_conference_control_participants method

`Retrieve conference participant list`

This function returns the full participant list of the conference.

```csharp
public static PulseErrorType pulse_conference_control_participants(IntPtr client, 
    ref IntPtr response)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| response | A pointer reference to a PulseConferenceControlParticipantsResponse struct. Upon successful return, the reference will point to a newly allocated PulseConferenceControlParticipantsResponse. The caller must later free this result, by calling pulse_conference_control_free_participant_list. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available to conference Hosts.
