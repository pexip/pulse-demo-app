# PulseConferenceControl.pulse_conference_control_breakout_close method

`Disconnect/close a breakout room.`

This function close a breakout room. Depending on the end_action specified on creation, participants will be transferred back to the main room or disconnected.

```csharp
public static PulseErrorType pulse_conference_control_breakout_close(IntPtr client, 
    uint response_room_id)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| response_room_id | the PulseRoomId that will be closed |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available to conference Hosts.
