# PulseConferenceControl.pulse_conference_control_status method

`Retrieve the status of the conference`

This function return the status of the conference

```csharp
public static PulseErrorType pulse_conference_control_status(IntPtr client, ref IntPtr response)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| response | A pointer reference to a PulseConferenceControlConferenceStatusResponse struct. If the function returns PULSE_SUCCESS, the reference will point to a newly allocated PulseConferenceControlConferenceStatusResponse. The caller must later free this result, by calling pulse_conference_control_free_status_response. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available to conference Hosts.

It it the responsibility of the caller, to free the data allocated for the PulseConferenceControlConferenceStatusResponse after use, by calling pulse_conference_control_free_status_response on the object.
