# PulseConferenceControl.pulse_conference_control_layout_svgs method

`Retrieve a list of available layout svgs for the conference.`

This returns a list of all available layout svgs for the given conference. This includes the inbuilt layouts plus any custom layouts available on this conference.

public static PulseErrorType pulse_conference_control_layout_svgs(IntPtr client,

| parameter | description |

| client | The Pulse handle |
| response | A pointer reference to a PulseConferenceControlLayoutSvgsResponse struct. Upon successful return, the reference will point to a newly allocated PulseConferenceControlLayoutSvgsResponse. The caller must later free this result, by calling pulse_conference_control_free_layout_svgs_response. |

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.
