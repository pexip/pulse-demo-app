# PulseRegistration.pulse_registrations_get_display_name method

`Get the server side reported display_name for this registration session.`

Get the server side reported display_name for this registration session.

```csharp
public static PulseErrorType pulse_registrations_get_display_name(IntPtr client, 
    out IntPtr display_name)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| display_name | Reference to a char variable, that will have point to a character buffer holding the display_name, if the call to this function returns successfully. (see note below) |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available when running the Pulse in public rest handling modes

Display_name is only available on Infinity V37+, and only for sso enabled calls. Otherwise the returned display_name will be NULL.

The returned string must be dereferenced by the client, by calling the pulse_registrations_display_name_free() function.
