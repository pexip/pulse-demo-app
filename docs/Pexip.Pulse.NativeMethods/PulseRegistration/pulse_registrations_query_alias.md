# PulseRegistration.pulse_registrations_query_alias method

Query a previously registered infinity server, for conference and device aliases.

Query a previously registered infinity server, for conference and device aliases.

```csharp
public static PulseErrorType pulse_registrations_query_alias(IntPtr client, string query, 
    int device_alias_limit, int service_alias_limit, out IntPtr result)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| query | Search query. Searches are case insensitive and only substring queries are supported, no support for asterisk, regexes or similar. |
| device_alias_limit | Limit the number of device results. A positive number for setting maximum number of results, '-1' for unlimited search results, and '0' to disable device alias searches. |
| service_alias_limit | Limit the number of conference results. A positive number for setting maximum number of results, '-1' for unlimited search results, and '0' to disable conference alias searches. |
| result | pointer to PulseRegistrationAliasList *, that will be filled in with the result. The caller is responsible for freeing this after use, by calling pulse_registration_alias_list_free(). |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function is only available when running the Pulse in public rest handling modes.
