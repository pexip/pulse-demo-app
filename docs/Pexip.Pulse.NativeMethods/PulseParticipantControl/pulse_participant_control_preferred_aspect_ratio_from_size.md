# PulseParticipantControl.pulse_participant_control_preferred_aspect_ratio_from_size method

`Request a specific aspect ratio from infinity.`

This function informs infinity that the client wishes to receive main video with a certain aspect ratio.

```csharp
public static PulseErrorType pulse_participant_control_preferred_aspect_ratio_from_size(
    IntPtr client, string? target_participant_uuid, uint width, uint height)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| target_participant_uuid | UUID of the target participant. Set to NULL for targeting this client. |
| width | The width of the new preferred aspect. |
| height | The height of the new preferred aspect. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

If target_participant_uuid is NULL (targeting this client), this can be called regardless of session role.

If target is specified, this function can only be called when the session has role HOST.
