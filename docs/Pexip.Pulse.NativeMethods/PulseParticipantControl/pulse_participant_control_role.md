# PulseParticipantControl.pulse_participant_control_role method

`Change the participant role`

Changes the role of the participant identified by the target_participant_uuid.

```csharp
public static PulseErrorType pulse_participant_control_role(IntPtr client, 
    string target_participant_uuid, PulseConferenceRole role)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| target_participant_uuid | UUID of the target participant |
| role | PULSE_CONFERENCE_ROLE_HOST or PULSE_CONFERENCE_ROLE_GUEST |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

This function can only be called when the session has role HOST.
