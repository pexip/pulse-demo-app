# PulseParticipantControl.pulse_participant_control_dtmf method

`Send DTMF digits to participant.`

This function sends DTMF digits to the participant identified by the target_participant_uuid.

```csharp
public static PulseErrorType pulse_participant_control_dtmf(IntPtr client, 
    string? target_participant_uuid, string dtmf_digits)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| target_participant_uuid | UUID of the target participant identified by the target_participant_uuid. |
| dtmf_digits | Pointer to a zero terminated char buffer containing the DTMF digits to send. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

Target_participant_uuid is ignored for gateway calls.

This function can only be called when the session has role HOST.
