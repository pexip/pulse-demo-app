# PulseDevices.pulse_device_copy method

Make a copy of a const PulseDeviceID.

If there is a need of making application side lists of devices returned from an iterator, call this function to make a copy. The copy should later be freed, by calling pulse_device_free().

public static IntPtr pulse_device_copy(PulseDevice device)
