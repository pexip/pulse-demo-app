# PulseDevices.pulse_device_iterator_new method

Create a new device iterator.

Creates a new device iterator for the specified media_type and direction.

```csharp
public static PulseErrorType pulse_device_iterator_new(IntPtr client, PulseMediaType media_type, 
    PulseMediaDirection media_direction, out IntPtr p_iterator)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| media_type | The kind of media device we want to list. Either PULSE_MEDIA_AUDIO or PULSE_MEDIA_VIDEO. |
| media_direction | Iterate input or output devices? |
| p_iterator | Reference to a PulseDeviceIterator pointer, that will be used as handle for any subsequent calls to the iteration functions. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.
