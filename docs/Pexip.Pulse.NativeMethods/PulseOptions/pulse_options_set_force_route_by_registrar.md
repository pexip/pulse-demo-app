# PulseOptions.pulse_options_set_force_route_by_registrar method

`Tells pulse to force route_by_registrar behavior.`

This function configures pulse to force route_by_registrar behavior. This applies to all connection attempts, meaning a client with no registration will fail all calls.

```csharp
public static PulseErrorType pulse_options_set_force_route_by_registrar(IntPtr client, bool enable)
```

| parameter | description |
| --- | --- |
| client | The Pulse handle |
| enable | The forced_route_by_registrar mode. |

## Return Value

PULSE_SUCCESS (0) on success, or a PulseError code in case of a failure.

## Remarks

By default, forced_route_by_registrar is disabled.
